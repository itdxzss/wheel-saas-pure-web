# 新建普群

## 目标

- 在拉群任务列表的“新建拉群任务”后增加“新建普群”入口。
- 按静态原型实现建群账号、群成员、群组配置、账号迁移和群权限表单。
- 账号分组选项读取现有 `/api/account-groups`，群组分组选项读取现有 `/api/group-folders`。
- 后端创建接口未交付前，仅在开发环境通过 `mock/` 模拟创建结果。

## 边界

- 沿用 `tenant:pull_task:create` 权限，不新增未经后端确认的权限键。
- “自定义号码”和“快速”只展示禁用态。
- 不实现原型中的“待确认”标签或提示，保留问号帮助提示。
- 不修改公共组件，不改变现有“新建拉群任务”及任务列表逻辑。
- 生产环境不启用本功能的 mock 路由。

## 验证

- 覆盖表单默认值、主要校验、群名预览以及页面入口的定向测试。
- 执行 Prettier、ESLint、Stylelint、typecheck、生产构建和 `git diff --check`。

## 2026-08-14 任务详情补充

- 结果明细展示后端返回的未脱敏创群号和计划群最后操作时间。

  业务阶段，不展示协议、冻结或账号状态等技术实现。

  不会虚构“已进入群配置”。
- 复用现有任务轮询和详情接口，不新增任务日志存储或公共组件。
- 定向流程测试 8 项及完整 TypeScript/Vue 类型检查通过。
