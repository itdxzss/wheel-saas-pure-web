# 变更记录：账号导入页认证码登录

- 日期 / 分支：2026-09-04 / `1.0.3-snapshot`
- 状态：本地开发与聚焦回归完成，待联调和真实主设备验收

## 目标

在账号导入页提供“认证码登录”，让异地主设备持有人输入控台显示的 `8888 8888` 完成导号。

## 范围

- In scope：入口按钮、手机号/分组/备注表单、会话轮询、认证码复制、成功/失败/过期反馈。
- Out of scope：公网推广页面、Android 原生协议、部署。

## 关键设计决策

- 前端不提交自定义认证码，固定值只由可信后端决定。
- 弹窗只显示后端 `WAITING_CONFIRMATION` 状态返回的认证码。
- 关闭弹窗停止轮询；会话仍活动时重新打开会继续查询，组件卸载会清理定时器。
