# 变更记录：拉人任务群组资源池

- 日期 / 分支：2026-08-22 / `1.0.3-snapshot`
- 状态：开发验证完成，待部署

## 目标

在保留原“群链接模式（手工粘贴或分组链接）”的前提下，新增独立“资源池模式”：创建任务选择一个自定义群组分组，执行时动态取群。

## 影响模块

- 拉人任务创建抽屉、配置、TXT 执行计划、列表和详情状态展示。
- 群组分组管理中的系统分组只读保护。

## 关键决策

- `PASTED_LINK` 原入口和交互保持不变；资源池使用独立 `RESOURCE_POOL` 模式。
- 资源池草稿只解析 TXT，群组分组在最终创建时冻结；执行阶段由后端动态取群。
- 资源耗尽展示“等待群组资源”，用户补群后手工点击继续。
- 不新增前端状态管理、公共组件或依赖。
