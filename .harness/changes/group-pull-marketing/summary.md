## 关键设计决策

- 创建页只保存为待启动，不提供草稿或保存并启动。
- 账号列表分页直接使用后端返回的占用展示字段，不逐账号请求任务详情；用户点击分组标签后才加载详情，并仅在当前列表会话缓存。
- 拉群营销群组明细使用隐藏子路由；现有“建群营销”菜单保持不变。
- 普通营销占用任务跳转复用现有详情抽屉，不新建第二套普通营销详情页。
- 模式二、模式三和其他营销尚无详情页时只展示任务信息，不生成不存在的跳转。
- 账号占用详情对同分组请求去重，并通过页面会话版本隔离快速切换和列表刷新产生的旧响应。
- 隐藏明细路由监听任务 ID 变化；名称字典失败时保留任务和群明细，按 ID 降级展示。
