# 营销任务列表模板信息

## 目标

在营销任务列表展示当前模板内容摘要与推广链接，并支持只读查看完整模板内容。

## 范围

- In scope：营销任务 API 类型、列表两列、只读预览弹窗、安全外链、任务侧更新模板后的列表刷新。
- Out of scope：模板选择列表关联、数据库、权限、协议层、营销任务调度和模板编辑能力。

## 影响模块

- `src/api/marketing-task.ts`：消费三个可空模板展示字段。
- 营销任务表格：任务名称后新增“营销模板预览”“推广链接”。
- 模板预览弹窗：以纯文本展示完整内容和正文，保留换行。
- 页面 composable：任务侧模板更新成功后刷新当前任务页。

## 关键设计决策

- 摘要由接口返回的模板内容和正文组合，表格单行省略，点击打开只读弹窗。
- 推广链接为空展示 `—`；非空时省略并通过 Tooltip 展示完整值。
- 仅 `http` / `https` 链接可点击，新窗口使用 `noopener noreferrer`；其他文本只展示、不跳转。
- 不读取页面已加载的模板列表做前端关联，避免受模板列表数量和缓存时效影响。
- 模板内容使用 Vue 文本插值，不使用 `v-html`。

## API

消费 `MarketingTaskRow` 新增的可空字段：

- `marketingTemplateContent`
- `marketingTemplateBodyText`
- `marketingTemplatePromotionLink`
