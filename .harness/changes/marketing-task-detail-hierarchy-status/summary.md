# 变更记录：营销任务明细层级与群组状态统一

- 日期 / 分支: 2026-07-19 / `1.0.1-snapshot`
- 需求来源: 营销任务明细第 4、5 条补充需求
- 状态: 已完成，待联调与部署确认

## 目标

把普通群组营销任务详情固定为“账号 → 实际发送群组”两级字段，并展示统一群组状态与最后有效发送结果的失败原因。

## 范围

- In scope: 详情 API 类型、六态群组状态映射、账号在线状态、两级固定字段、失败原因展示。
- Out of scope: 任务轮询频率、任务创建/调度、历史群营销、建群营销。

## 影响模块

- 路由: 无变化。
- 页面: `GroupMarketingDetailDrawer.vue` 一级只展示在线状态、发送账号、账号发送总条数、明细；二级只展示群组状态、群名称、单群发送条数、最后发送时间、执行情况。
- API: 新增消费 `accountTargets[].loginState` 与 `groups[].executionReason`；群组状态改为统一六态。
- Store: 无变化。
- 权限: 无变化。

## 关键设计决策

- 在线状态复用账号页现有 `loginStateLabel` / `loginStateTagType`，不维护第二套映射。
- 执行情况为失败时在同一字段内展示后端统一失败原因。
- 删除旧的首群折叠摘要 helper 及其测试，不保留群组链接、最近原因等旧展示路径。
- 保留现有详情 5 秒轮询逻辑，不在本次变更中调整。
