# 超链任务 H1 列表

## 范围

- 新增超链任务动态路由、完整列表页和 API 封装。
- 实现五项筛选、10/20/50/100/200 分页、任务名搜索自动 200、六张当前页指标卡和 15 个逻辑列。

- 暂停/恢复/停止调用 H3 action；START 通过具名事件进入 H3 报价确认边界。
- 编辑/查看/复制、详情、访问趋势分别通过 H2/H4/H6 具名事件等待集成，不伪造成功。

- 顶部价码与国家候选读取 H2 的 `create-context`；失败时列表仍可使用并提供重试。
