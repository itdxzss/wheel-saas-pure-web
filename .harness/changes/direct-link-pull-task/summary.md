# 群链接模式（新）

在原创建抽屉增加 DIRECT_LINK tab。旧模式及其草稿行为保留，新模式仅页面内存暂存输入，创建时一次 multipart 提交；没有管理分组、执行策略、群信息设置或管理员提权。

接口：POST /api/pull-tasks/standard/direct-link，request JSON Blob 与 files；requestId 在相同内容的失败重试间保持。列表、详情和执行明细区分新模式及阶段 10 拉手进群。

实现完成，已于 2026-09-19 部署第二套 perf2，未提交或推送；运行静态制品哈希核验一致。验证浏览器无登录态，登录后页面及真实业务验收待完成。默认仍打开旧模式；新模式切换及再次打开只加载分组，不恢复或写入旧草稿。输入只保存在当前页面内存，刷新页面不恢复。

验证结果：

- 拉群相关 Node 回归 151/151 通过；含无草稿一次提交、重试 requestId、输入变化更换 requestId、站台条件校验及阶段 10 / 入群审批显示。
- tsc + vue-tsc 通过；目标文件 ESLint、Stylelint、Prettier 通过；git diff --check 通过。
- Vite 生产构建通过。pnpm 本机触发依赖自动检查及网络失败，因此直接调用已安装 node_modules/.bin 下同等检查工具，未变更依赖。
- 本地 Playwright 合成页面验证 2/2 通过：旧输入与分组保留、新模式关闭重开不读取草稿、创建请求中无草稿/管理员/群设置字段、提交禁切 tab/关闭、失败重试 requestId 保持。
- Playwright 的全部 /api 请求由测试夹具拦截；未连接真实租户、未进行真号入群或拉人验收。

2026-09-19 UI 优化（主仓库本地，尚未提交或部署）：新模式采用双栏卡片布局，左侧目标群组/料子/备注，右侧分组参数与账号；站台数量和分组相邻。料子展示抽为独立组件。新模式只保留底部创建入口，按钮随自动启动状态显示“创建并启动”或“创建任务”，保留原表单字段、约束、默认值及提交逻辑。
