# 群主退群

- 日期: 2026-08-22
- 状态: 本地实现完成，未部署

## 目标

在群详情抽屉底部提供手动“群主退群”，并在标准拉群创建抽屉为新群模式、群链接模式共同提供“拉人完成后群主退群”开关。

## 页面规则

- 能力读取与执行都通过 `src/api/group.ts`，页面不直接请求协议端，也不读取 metadata。
- 后端本地投影确认当前账号是建群者，且群内存在我方正常控端管理员或可提升的普通控端成员后，按钮才可用。
- 已有我方控端管理员时直接退群；否则后端固定选择普通控端成员设为管理员，页面不展示“选接管账号”。
- 标准任务开关默认关闭，业务人员创建任务时手动选择；两个创建模式使用同一个字段。
- 退群结果不改变已完成的 TXT 拉人任务和群组既有分组流转。

## 影响范围

- 群列表详情抽屉、群 API 和退群 composable。
- 标准拉群创建/已保存配置、API 类型与创建 composable。
- 对应静态布局、API 和状态测试。
