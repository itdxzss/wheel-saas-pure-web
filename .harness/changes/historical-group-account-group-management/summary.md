## 目标（一句话）

移除历史群操作账号选择，以账号组直接加载、刷新和管理群，并补齐账号、链接、国家和创建时间等群级字段。

## 缺口拆解 / 任务清单

- [x] 历史群 API 合同改为 `accountGroupId` 和分页参数。
- [x] 选中账号组立即加载历史群，刷新时显式调用实时同步接口。
- [x] 列表平铺分页并按确认顺序展示新列。
- [x] 关联账号显示一个号码并通过 tooltip 展示全部。
- [x] 没有在线管理员时保留群行并禁用操作。
- [x] 详情、成员操作和拉群创建不再提交操作账号 ID。
- [x] 契约测试、页面测试、typecheck 和 build。

## 关键设计决策

- 页面不展示“未校验”状态；缺失缓存字段统一显示 `--`。
- 列表不展示每个账号的角色或在线状态，避免把群级页面重新做成账号级页面。
- 操作可用性完全使用后端 `operable/disabledReason`，前端置灰只作为体验提示。
- 刷新成功后重新请求当前页，分页列表始终走同一读取接口。

## 影响

- API：历史群列表/刷新/详情/成员操作和拉群任务参数变化。
- 路由与菜单：无变化。
- 数据库、Redis：无前端变更。
- 远程环境：不操作。

## 回滚

- 恢复旧账号选择器、旧 API 类型和旧分区表格即可；不涉及前端数据迁移。
