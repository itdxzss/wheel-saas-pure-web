# 养群剧本三栏编排

## 问题与结果

养群剧本原先把每条消息的完整表单放在折叠列表中，发送项增加后难以定位和比较。参考工作区 `养群系统前端最终版/index.html`，将剧本库新建、编辑抽屉改为角色配置、消息顺序、单条编辑 / 预览三栏。桌面端各栏独立滚动，底部保存固定可见，窄屏调整为上下布局。

## 交互与边界

- 角色统一命名，改名同步到关联消息；支持按角色添加消息，使用中的角色不可直接删除。
- 消息摘要卡片支持拖动、上移、下移、复制、插入、删除。选中状态跟随稳定消息 key，复制后的内容独立。
- 沿用 2–100 条消息、至少一条管理员和一条推手消息的规则。保存时将缺失内容或错误等待区间定位到对应消息。
- 默认等待用于本次编辑中新增 / 选择沿用的消息；应用到全部需确认，已单独设置的消息不会随默认值变化。保存每条消息最终等待数值，不增加后端字段。第一条不等待，预计时长排除第一条。
- 继续复用现有素材、文字 / 图片 / 按钮编辑和预览组件；管理员账号仍在创建任务时分配。任务创建页原有编辑 / 只读行为保持兼容。
- 原型的语言、说明和引用回复没有纳入本次实现。没有独立保存无消息角色或默认等待模式。
