## 实现范围

- 同一抽屉公开 `openCreate/openEdit/openView/openCopy` 四个入口，左侧为 WhatsApp 实时预览，右侧为基础信息、消息内容、发送策略、受众与发布四段表单。
- 支持普通按钮、卡片按钮、单图文；历史双图文编辑时锁定消息类型但内容可编辑，新建/复制不提供双图文。
- 支持模板、策略、数据包引用；数据包名称会非破坏性自动建议任务名，用户手工命名后不再覆盖。
- 素材选择支持服务端搜索、分页继续加载、JPG 批量上传、更换与清空；受保护图片统一经带 Bearer 的 Axios 下载 Blob、创建 ObjectURL，并在最后引用释放或迟到请求完成时 revoke。
- 完整账号范围筛选子抽屉支持名称及 tags 搜索、250ms 实时试算、旧请求取消和响应防串；当前后端未返回 tags 时明确只按名称匹配，不伪造标签。

## 审查项关闭情况

1. 素材和实时预览不再把 `/api` 直接作为 `img src`，统一使用认证 Blob/ObjectURL 缓存并正确回收。
2. 账号试算在防抖开始时立即清空旧结果并中止旧请求；未知、旧版本、加载中或失败结果均禁止启用提交。
3. 最大执行账号数使用最新 account-match-count 的 `maxConcurrentNum`。
4. 7 秒最终确认后重新即时试算并重新执行完整表单校验，不复用核对前结果。
5. 数据包、模板和素材均使用真实接口的服务端搜索与分页/继续加载，不再固定截取前 200/100/50 条。
6. `linkDescription` 输入与领域校验统一最多 512 字。
7. 自定义注册天数在进入 wire 前转为正整数；空串和非法文本不会被发送。
8. 分组搜索匹配名称及可选 tags，并在页面注明当前后端无 tags 的事实边界。
9. 服务端未解析出 `public + hyperlink` 默认组时显示依赖错误、强制新建/复制为仅保存并禁用启用选项。
10. 选择数据包会把数据包名称写入空任务名或上一次自动建议值，不只是 placeholder。
11. `maxUse`、`maxSend`、`cycle`、`delay`、最大执行账号及消息间隔补齐数值、整数、范围和一位小数校验；好友数/存活天数的 0 下限不会被清空。
12. 大洲 wire 只使用七个完整枚举值，不发送 AS/EU 等短码。
13. 国家包含与排除可同时存在，仅同一国家重叠时报错。
14. detail 的账号筛选由后端统一 normalizer 失败关闭；前端只接收规范化结果。

## 保存、准备与冲突处理

- 所有纯 create（包括仅保存）都进入 7 秒最终核对；enabled create 获取服务端 Quote，仅保存不报价，edit/copy 遵循冻结设计不走该核对。
- `202/PROCESSING` 保存任务 ID 和 version 后轮询；查询失败保留准备状态并提供重试，服务端 `FAILED` 保留表单并切换到 edit，可重新试算、校验并提交准备。
- 业务码 40910 时不关闭抽屉、不覆盖表单，显示乐观锁冲突并提供显式“重新加载服务器版本”。
- 资源接口失败均保留入口、错误态和重试，不隐藏按钮、不使用 mock。
