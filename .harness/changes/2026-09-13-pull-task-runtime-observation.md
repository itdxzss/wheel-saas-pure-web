# 群执行运行说明

- 分支：主仓库 `1.0.3-snapshot`。
- 范围：现有群列表四列、单群明细运行摘要及观察刷新。

## 实现

- 原任务标签、业务阶段、原因与最近业务执行时间保留；下方补充后端 observation 的运行说明、轮次/批次、依据和下一步。
- 时间只按服务端观察快照计算；没有等待起点明确显示未记录，不使用用户电脑时钟推断故障。
- 群列表及单群明细提供每 10 秒自动刷新和手动刷新。页面隐藏、KeepAlive 停用、关闭抽屉或已有刷新请求时不发起自动刷新；可关闭开关。
- 失败保留上一次数据并提示可能过期。请求序号隔离切换群/任务后的迟到响应；编辑尚未应用的筛选条件时自动刷新不抢先应用。
- 保留原列宽。筛选栏按原行为提取为 PullTaskDetailSearch，群列表 Drawer 保持在 600 行以内。
- 新增接口类型仅对应后端只读 observation，不改写入请求和状态映射。

## 验证

- 28 项前端聚焦测试通过，覆盖现有展示、只读刷新、失败保留快照、关闭后不再读取、切群迟到响应与筛选输入。
- tsc、vue-tsc、修改文件 ESLint/Stylelint/Prettier 和 Vite 生产构建通过。制品 `/private/tmp/pull-observation-web-build`。
- 隔离 Chrome 用本地测试数据渲染真实 Drawer，检查状态/阶段保留、批次说明、等待时长、刷新开关与过期提示。截图 `/private/tmp/pull-observation-ui/groups.png`。
- 用户已授权提交、推送并部署第一套环境 test1；没有进行线上账号/群操作。

撤销本次 observation 展示、刷新逻辑与筛选栏提取即可；后端原字段和业务写流程未改变。
