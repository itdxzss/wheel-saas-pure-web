# 变更记录：营销任务数据导出前端

- 日期 / 分支: 2026-07-29 / `1.0.1-snapshot-wyfBranch`
- 需求来源: 《营销任务数据导出 PRD V1.1》及后端设计方案
- 状态: 前端开发完成，等待后端接口联调与页面人工验收

## 目标

在普通营销任务列表增加受权限控制的数据导出入口，支持按国家导出实际进群数据和导出任务全量数据，并在后端异步生成成功后自动下载。

## 范围

- In scope:
  - 营销任务列表工具栏导出按钮与勾选校验。
  - 两种导出模式弹窗、国家多选搜索、全选与清空。
  - 创建异步导出任务、轮询生成状态、成功后自动下载。
  - 生成中防重复、无数据、失败和过期提示。
  - `tenant:marketing_task:export` 按钮权限。
- Out of scope:
  - 导出记录弹窗和历史文件手动下载入口。
  - 前端生成 Excel、统计业务数据或国家共享区号归属。
  - 修改营销任务调度、发送、状态和明细逻辑。

## 影响模块

- 路由: 无。
- 页面: `src/views/task/group-marketing/`。
- API: 新增 `src/api/marketing-task-export.ts`。
- Store: 无，状态仅保存在页面 composable。
- 权限: `tenant:marketing_task:export`。

## 关键设计决策

- 导出按钮位于“新增营销任务”左侧；未勾选时保持可点击，并按 PRD 展示提示。
- 导出工作流拆到独立 `useMarketingTaskExport.ts`，不继续扩大既有 800 行页面 composable。
- 国家来源只调用后端营销导出国家接口，前端不使用生产 mock、不硬编码国家数量。
- 后端异步生成，前端使用 `jobId` 轮询；本期成功后自动下载，不展示导出记录入口。
- 国家和共享区号映射、文件名、Excel 内容及快照统计均以后端为准。
