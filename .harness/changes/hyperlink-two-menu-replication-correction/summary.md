# 变更记录：超链两个菜单复刻纠偏

- 日期：2026-08-27～2026-08-28
- 分支：`1.0.3-snapshot`
- 状态：已提交、推送并部署第一套环境

## 变更概述

- 数据包页补齐蓝色说明与禁导警告、全部/今天/昨天快捷日期、UV 百分比、国旗国家按钮和搜索/重置布局。
- 数据包管理区补齐本页包数/号码数/空包徽标、五个顶部操作、组合业务列、彩色行按钮和更多菜单。
- 数据包名称单元格展示图标、可点击名称、主国家和备注；号码使用与投递漏斗改成彩色占比组合展示。
- 号码抽屉收敛为竞品的序号、手机号、入库时间三列；真实号码导出与失败重置调用后端接口。
- 模板页补齐说明、统计条、消息类型快捷按钮、三列管理表和图标操作；编辑抽屉继续提供实时预览与单 URL 按钮编辑。

## API / 契约

- 数据包列表新增 `primaryCountryIso2`，筛选继续提交 `minUvPercent`、`maxUvPercent`、`countryIso2s`。
- 对接单包/批量 TXT 导出和失败重置接口；导出使用独立 `tenant:hyperlink_data:export` 权限。
- 批量点击记录导出已对齐竞品的 TXT（仅收件人手机号）与 CSV（含数据包上下文）两个选项。
- 点击分析已改为 880px 右抽屉，补齐日期快捷项、国家快捷筛选/更多国家、国家分组、两种分析模式、多阈值档位、占比条和分档导出。
- 后端点击事实源尚未接入时，抽屉和导出明确返回真实空结果，不生成假数据。

## 关键约束

- 马来西亚、新加坡、中国、香港、澳门、台湾的既有数据包在前端禁用导入；最终安全校验以后端上传内容为准。
- 所有表格、按钮组、日期范围、抽屉和分页继续复用 pure-admin / Element Plus。
- 页面不直连 Axios，不在生产代码加入 mock。
