# 拉群任务原型字段前端对齐

## 目标

先对齐普通群链接创建页中非营销、非“后期”的原型字段，供产品验收；后端请求合同和执行逻辑后续同步。

## 范围

- 前端表单字段、名称、默认值、必填展示和进群顺序表头。
- 不包含模板与内容、营销分组及原型“后期”字段。
- 不修改后端，不把新增字段混入现有创建请求。

## 状态

- 需求对账：完成。
- 前端实现：完成，等待用户页面验收。
- 自动化验证：完成。
- 页面验收：本地生产预览可启动，但浏览器没有业务系统登录态，停留在登录页；需在用户已登录环境中刷新验收。

## 实现记录

- 扩展 `StandardPullTaskCreateForm`，补齐群组分组、执行策略、完成归档和群信息设置字段。
- 新增 `PullTaskStandardGroupSettings.vue`，承载群资料、权限和限时消息字段。
- 移除原型标记“后期”的“拉手风控时间”展示；其旧合同默认值仅保留在提交状态中。
- 群头像支持重新选择和清除文件名，便于前端字段验收。
- 群组分组读取真实 `/api/group-folders` 接口；账号归档分组复用账号分组接口。
- 进群顺序表补充“进群料子”和“状态”口径。
- 当前 `POST /api/pull-tasks/standard` 仍使用显式旧字段白名单；新增前端字段不会进入请求体。
