# 账号分组数量展示统一

## 范围

按用户要求，账号分组展示统一为 `分组名称（总 N / 在线 M）`。
超链任务、超链策略和通讯录营销的账号分组筛选明确排除，不修改其接口或文案。
仅前端改动，不改变分组选项 ID、提交参数、选人资格、任务调度或后端统计口径。

## 实现

- 共用 `src/utils/account-group-label.ts` 格式化总数与在线数。
- 账号、导入、注册、历史群、养号、进群、拉群、普群创建及营销相关的分组选择框统一格式。
- 账号和任务列表/详情复用页面分组 Ref，通过页面级 provide/inject 共享，避免逐行请求。
- 建群营销列表初次加载时读取分组数量；剧本营销保留原候选接口，另读取分组数量，数量请求失败不阻止原候选选择。
- 拉群在线候选及建群正常可用数量作为独立附加指标保留。
- 历史记录有 ID 时按 ID 关联；只有名称时要求唯一匹配。进群旧列表的斜线拼接快照只有唯一可解析时才附加当前数量。
- 已删除、未加载或歧义分组不冒充 0，显示 `—` 或“数量暂不可用”。总数/在线数是当前已加载分组快照，并非任务创建时快照。
