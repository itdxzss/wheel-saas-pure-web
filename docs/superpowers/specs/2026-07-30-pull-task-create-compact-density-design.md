# 新建拉群营销任务页面紧凑化设计

## 目标

提高“新建拉群营销任务”页面的信息密度，让常用笔记本屏幕在不改变浏览器缩放的情况下显示更多表单行，减少纵向滚动。

## 已确认方案

采用保守紧凑化方案，只调整视觉密度：

- 保持现有五个配置区块、字段顺序、两列布局和移动端断点不变。
- 页面正文与表单标签字号统一收敛到约 13px，区块标题收敛到约 14px。
- 缩小页面头部、卡片头部/内容区、表单项、提示框和底部操作栏的上下留白。
- 缩小账号资源卡片内部间距与空状态留白。
- 控件继续使用 Element Plus，不新增组件、不改变字段值或交互。

## 实现边界

- 在创建页根组件集中增加作用域内的紧凑样式，通过根容器约束影响范围。
- 不调整拉群任务列表、独立“拉群营销”菜单或其他页面。
- 不改 API、路由、草稿模型、校验逻辑和提交逻辑。
- 不把两列布局改成三列，不增加折叠面板。

## 验证

- 增加页面源码测试，固定根容器下的关键字号和间距规则。
- 运行拉群任务创建页相关测试。
- 运行 `tsc`、`vue-tsc` 和生产构建，确认样式调整不影响编译。
