# 营销任务群组明细 Element Plus 表格设计

## 背景

营销任务详情抽屉的群组明细当前使用 CSS Grid。新增“当前关系、失败、跳过”等字段后，网格被设为固定最小宽度，导致“最后发送时间”和“最后执行”只能在较宽视口下直接看到，而且用户不能在页面上拖动调整列宽。

## 目标

- 将账号展开区的群组明细改为 Element Plus `ElTable` / `ElTableColumn`。
- 保留现有字段和顺序：当前关系、最后协议状态、群名称、群 GID、成功、失败、跳过、最后发送时间、最后执行。
- 所有普通列沿用 Element Plus 的表头拖动调宽能力。
- “最后发送时间”和“最后执行”不固定；表格宽度超出展开区时，通过表格底部横向滚动查看。
- 保留群名称、GID、执行原因的溢出提示，以及空明细提示。

## 实现方案

在现有外层账号 `ElTable` 的展开插槽内嵌套一个带边框的 `ElTable`。每个字段改为明确的 `ElTableColumn`，状态类字段继续调用现有状态映射函数，数值与时间继续沿用现有数据和格式化函数。

内层各列设置合理的初始宽度或最小宽度，使总宽度自然超过狭窄展开区并由 Element Plus 生成横向滚动条。不设置 `fixed`，也不保留 CSS Grid 的强制最小宽度、网格列定义及自制表头/行样式。

## 边界与验证

- 不修改接口、轮询、状态含义和字段顺序。
- 不修改外层账号汇总表格。
- 先增加源码结构回归测试，确认内层使用 Element Plus 表格、列顺序正确、末两列未固定，并观察测试失败。
- 实现后运行定向测试、类型检查、Lint 和生产构建。
