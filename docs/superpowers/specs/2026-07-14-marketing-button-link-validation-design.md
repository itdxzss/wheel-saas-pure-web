# 营销模板按钮与任务模板默认值调整设计

## 目标

精确调整营销模板按钮超链的初始状态、添加行为和跳转链接校验，同时让新增群营销任务的营销模板下拉框保持未选择状态。

## 范围

- 营销模板新建与编辑页面中的消息按钮编辑器。
- 营销模板保存前的按钮数据校验。
- 新增群营销任务抽屉中的营销模板初始值。
- 与上述行为直接相关的自动化测试。

不调整账号分组的默认选择，不改变按钮最多三个的限制，不修改后端接口或数据结构，也不重构无关页面。

## 交互设计

### 消息按钮初始状态与添加行为

- 新建营销模板时，按钮列表只包含一个按钮。
- 首个按钮类型为“链接跳转”，按钮文字保留现有默认文案，跳转链接为空。
- 编辑已有模板时完整保留后端返回的按钮；若旧模板没有按钮，则使用一个空链接的“链接跳转”按钮作为回退。
- 点击“添加按钮”时新增一个“快捷回复”按钮，延续当前新增行为。
- 按钮总数最多为三个；达到上限后禁用添加按钮并显示现有上限文案。
- 至少保留一个按钮，延续当前不可删除最后一个按钮的行为。

### 跳转链接输入与类型切换

- “链接跳转”按钮的输入框不再填入示例链接默认值。
- 按钮从其他类型切换为“链接跳转”时清空旧参数，避免复制内容或快捷回复参数被误当作 URL。
- 新增的“快捷回复”按钮不显示链接输入框；只有用户主动选择“链接跳转”后才进入链接校验流程。
- 用户将按钮切换为非链接类型后，该按钮的链接校验错误立即失效。

### 链接校验与可见反馈

链接校验使用 Element Plus `el-form-item` 动态规则完成，以获得标准的错误文本和输入框红色状态。保存入口先触发表单校验，通过后再调用现有保存逻辑。

- 空字符串或仅包含空白时，显示“请输入跳转链接”。
- 非标准链接时，显示“请输入标准的跳转链接”。
- 接受完整的 `http://`、`https://` 链接。
- 接受 `www.example.com/path`、`example.com/path` 等无协议常规链接；校验时临时补充 HTTPS 协议，不改变用户实际填写和提交的值。
- 允许 URL 中正常使用的路径、查询和片段字符，例如 `/`、`?`、`&`、`=`、`#`、`%`、`-`、`_` 和 `.`。
- 拒绝汉字、空格、控制字符、非 HTTP(S) 协议以及无法解析为有效主机地址的内容。
- 用户输入有效链接后，Element Plus 自动清除该字段的红框和错误文案。

保存状态层复用同一链接校验函数，作为组件校验之外的防御性校验，避免绕过表单组件时提交非法数据。保存层返回的提示文案与字段规则保持一致。

## 组件与数据流

### `useMarketingTemplatePage.ts`

- 将默认按钮集合从三个改为一个空链接的链接按钮。
- 提供可复用的链接校验函数，返回空值、格式错误或通过三种结果。
- `validateForm` 调用该函数并返回精确提示。
- API payload 映射保持不变，只提交按钮的类型、文字和参数。

### `MarketingButtonEditor.vue`

- 保留最多三个按钮和新增快捷回复按钮的逻辑。
- 链接类型的 `el-form-item` 使用按钮数组索引生成动态 `prop`，并绑定链接校验规则。
- 类型切换为链接时清空参数。
- 组件继续使用 Element Plus 输入框和表单项，不添加自绘控件或全局 DOM 监听。

### `MarketingTemplateDrawer.vue`

- 持有 `el-form` 引用。
- 保存按钮先执行 Element Plus 表单校验；校验通过后才发出原有 `save` 事件。
- 预览模式和按钮为空时的保存禁用逻辑保持不变。

### `useGroupMarketingTaskPage.ts`

- `emptyCreateForm` 已将 `marketingTemplateId` 初始化为空，保持该定义。
- 删除打开新增抽屉后自动选择第一条营销模板的逻辑。
- 营销模板列表照常加载，用户必须主动选择后才能创建任务。

## 错误处理

- 字段级链接错误在对应按钮输入框下方显示，并将输入框标红。
- 状态层校验仍阻止 API 请求并使用已有 Element Plus 消息提示。
- 非链接按钮不受链接规则影响；复制内容的现有必填逻辑保持不变。
- 营销模板未选择时，群营销任务保存继续提示“请选择营销模板”。

## 测试设计

按照 TDD 先写失败测试，再实现最小改动：

1. 新建营销模板仅生成一个链接按钮，且链接值为空。
2. 编辑无按钮的旧模板回退为一个空链接按钮。
3. 新增按钮仍默认为快捷回复，并继续限制最多三个。
4. 空链接保存被拒绝，提示“请输入跳转链接”。
5. 汉字、空格、非法协议和不可解析内容被拒绝，提示“请输入标准的跳转链接”。
6. 完整 HTTP(S) 链接和无协议域名链接通过校验。
7. 组件源码测试确认动态 `el-form-item` 规则、表单保存校验和红框能力接入。
8. 打开群营销新增抽屉后，营销模板列表正常加载，但 `marketingTemplateId` 仍为空。
9. 运行相关 Node 测试、项目 typecheck、lint 和 build；若仓库现有问题导致命令失败，记录与本次改动的关系。

## 验收标准

- 页面初始只清楚展示一个消息按钮。
- 只有点击“添加按钮”才出现第二、第三个按钮，新增按钮默认快捷回复。
- 链接输入框无默认值。
- 保存空链接时显示“请输入跳转链接”且输入框标红。
- 保存非法链接时显示“请输入标准的跳转链接”且输入框标红。
- 无协议的常规域名链接可以保存。
- 群营销新增抽屉的营销模板下拉框保持空白。
- 自动化测试和项目可用的静态检查、构建验证均有新鲜输出证据。
