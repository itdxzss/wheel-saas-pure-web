# 账号列表核心列顺序设计

## 目标

账号列表中将“分组”“账号状态”“登录”依次移动到“账号”列之后，其余列相对顺序不变。

## 方案

- 同步调整 `accountListColumns` 和 `AccountListTable.vue` 的显式列顺序。
- 调整每个模板列使用的 `dynamicColumns` 索引，保持列设置、隐藏和实际表格一致。
- 最终顺序开头为：头像、账号、分组、账号状态、登录、国家、IP来源、账号类型/设备、协议、IP地址、渠道/来源。
- 不修改接口、字段渲染、公共表格组件或其他页面。

## 验证

- 源码契约测试断言列配置和表格模板都满足指定顺序。
- 运行账号表格测试、TypeScript 检查和改动文件 ESLint。
